Study OS｜UX Companion Preview

這版是使用體驗測試版，資料與私人同步架構不變。

這次可以直接試的重點：

1. Sidebar 重做
- 圖示與文字都會正常顯示
- Active 不再是一整大塊紫色
- 改成淡紫背景 + 左側細紫線
- 學習 / 洞察 / 設定重新分層
- 複習、題目需要處理時會顯示 Badge
- 手動收合 Sidebar；收合後 Hover 顯示名稱

2. 窄桌面視窗 = 陪讀模式
- Mac/PC 有滑鼠時，視窗縮窄不再直接變成手機版
- Sidebar 自動縮成 icon rail
- 內容改成單欄、卡片化
- 適合課程影片放一邊、Study OS 放另一邊
- 真正手機仍使用底部 Tab Bar

3. 專注模式升級
- 開始計時後，會出現持續存在的 Mini Focus Dock
- 切到課程 / 複習 / 題目頁，計時不會消失
- Dock 可暫停 / 繼續 / 展開 / 完成
- 窄視窗時 Dock 會變成陪讀卡片

4. 本週 PLAN × DONE 圖表互動
- 滑鼠移到柱狀圖：顯示日期、PLAN、DONE、差額
- 今天會有特殊標記
- 點某一天：展開那一天的 DONE 詳細紀錄

5. 視覺
- Logo 收小
- Sidebar 密度提高
- 版本字樣不再放在品牌區
- 同步狀態更低調

建議測試方式：
A. 先把 Safari/Chrome 放大，看完整 Sidebar。
B. 慢慢把視窗縮窄到約 700px，觀察 Sidebar 自動變 icon rail。
C. 開「專注模式」→ 開始，再切不同頁面，看 Mini Focus Dock。
D. 到「統計」，把滑鼠移到本週 PLAN × DONE 柱子上。
E. 點一根柱子，看單日明細。
