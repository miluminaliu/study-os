Study OS｜UX Master Final

這版把先前討論的使用體驗優化整合到同一版。
同步架構、Apps Script、Google Sheet 資料結構不重做。

已整合：

【Sidebar / Navigation】
- Active 狀態改為淡底 + 左側細線
- 學習 / 洞察 / 設定分層
- Sidebar 可收合、收合後 Hover Tooltip
- 複習與題目顯示待處理 Badge
- 窄桌面視窗自動變成 icon rail
- 真正手機仍使用底部 Tab Bar
- 網站每次重新開啟預設回「今天」

【窄視窗 / 陪讀模式】
- Mac/PC 小視窗不硬套手機版
- 單欄內容、icon rail、精簡資訊
- 適合一邊看課一邊開 Study OS
- 專注計時會固定成 Mini Focus Dock
- 切頁仍持續計時

【統計圖】
- Hover 顯示日期、PLAN、DONE、活動時間分布、差額
- Hover Crosshair
- 今天特殊標記
- 點柱子看當天 DONE 明細
- 圖表自動依當週最大值縮放

【Dashboard】
- KPI Hover 顯示公式/定義
- KPI 加 7 日 Sparkline
- 本週 DONE 顯示與上週變化
- KPI / 本月英文 / 刷題 / 正確率可點擊導向對應頁
- 「下一步」項目可直接展開，不必換頁
- 科目卡 Hover 顯示已看課、到期、本週投入、平均成熟度

【課程】
- 即時搜尋
- 搜尋關鍵字高亮
- 支援課號與自然輸入（例如「生物 053」）
- 搜尋 / 類型 / 重點 / 狀態 / 只看需要處理 都會記住
- 顯示「清除篩選」
- 課程 Hover 顯示詳細 Preview
- 成熟度顯示百分比 + 文字狀態
- 進度條 Hover 解釋成熟度來源
- 桌機 Hover 出現「看課 / 複習 / 刷題」Quick Actions
- 桌機右鍵課程顯示 Context Menu
- 手機課程卡可 Swipe 露出完成/複習
- 手機長按課程可開快捷選單

【今天】
- 日期三格切換：昨天 / 選定日 / 明天
- 離開今天時顯示「回今天」
- 過去日期只回顧 PLAN/DONE，不用今天成熟度假裝回推歷史複習
- PLAN Hover 顯示開始時間、預計時間、成熟度、上次學習
- 沒有到期複習時直接顯示下一堂與距離日期
- 新 DONE 有完成微動畫

【Feedback】
- Undo Toast 延長為 8 秒
- Toast 加倒數條
- 初次無快取同步顯示 Skeleton
- 同步中按鈕有 loading
- Sidebar 同步狀態平常低調，Hover 才顯示四張表筆數與最後同步時間
- 切頁記住捲動位置，回來不會跳回最上面

【專注模式】
- 持續 Mini Focus Dock
- 暫停 / 繼續 / 展開 / 完成
- 切頁不消失
- 窄視窗時自動變成陪讀卡片

建議先實際使用 2–3 天，再決定哪些互動太多、哪些值得保留。
